# Level 6.16：样本级污染检测与条件干预

## 1. 完成情况

- 3 个模型种子分别训练独立线性 probe。
- detector train / validation / test 按随机种子隔离；干预评估再使用另一批全新种子。
- 完成 3 个 leave-one-model-out 测试和 18 个正式条件干预。
- probe 只使用 12 个推理时可观测动力学特征，没有使用 donor、答案或干净参照。

## 2. 每模型独立污染检测有效

| 模型 | 独立测试 AUC | clean FPR | 污染 TPR | 检测准确率 |
|---:|---:|---:|---:|---:|
| 606 | 0.884 | 5.00% | 66.17% | 80.58% |
| 808 | 0.867 | 4.50% | 52.58% | 74.04% |
| 1001 | 0.850 | 5.25% | 50.17% | 72.46% |
| 均值 | **0.867** | **4.92%** | **56.31%** | 75.69% |

这是第一个无需 donor 或 clean reference、仅根据单次 Memory 写入动力学就能在新样本上识别污染的正结果。即使是困难模型 seed 808，AUC 也达到 0.867，并能在约 5% clean FPR 下检出约 52.6% 的污染。

三个模型权重绝对值最大的共同特征都是 **rewrite_relative**，即本次新旧 Memory 的相对改写幅度。说明污染在传播后的首个写入中确实产生了可观测动力学异常，而不仅存在于隐藏的 donor 方向中。

其他特征权重随初始化变化明显：seed 606 更依赖 gate 与 Memory 范数；seed 808 更依赖 encoded norm；seed 1001 更依赖 compression entropy。共同信号存在，但各模型对辅助信号的使用方式不同。

## 3. 跨初始化排序部分迁移，阈值不迁移

| 留出模型 | 测试 AUC | clean FPR | 污染 TPR |
|---:|---:|---:|---:|
| 606 | 0.806 | 0.00% | 12.00% |
| 808 | 0.817 | **25.50%** | 70.25% |
| 1001 | 0.771 | **24.50%** | 62.25% |

leave-one-model-out AUC 仍为 0.77–0.82，说明“异常改写可检测”的排序规律具有一定跨初始化迁移能力；但在其他模型上校准的固定阈值完全不可靠。对 seed 808 和 1001，clean FPR 上升到约 25%；对 seed 606 则过于保守，只检出 12%。

结论是：**特征方向可以部分迁移，分数标尺和决策阈值必须按模型校准。**

## 4. 条件干预部分缓解了 seed 808 反向，但未解决

| 模型 | 平均准确率变化 | 正/负设定 | corrected / harmed | 污染触发率 | clean 触发率 |
|---:|---:|---:|---:|---:|---:|
| 606 | +0.32 pp | 4 / 2 | 273 / 250 | 70.06% | 7.33% |
| **808** | **-0.19 pp** | 2 / 4 | 266 / 280 | 49.76% | 6.46% |
| 1001 | **+1.17 pp** | 5 / 1 | 260 / 176 | 53.75% | 5.17% |
| 总体 | **+0.43 pp** | 11 / 7 | 799 / 706 | 57.86% | 6.32% |

相较 Level 6.15.2 的固定 scale=0.20：

- seed 808 从 `-1.83 pp` 改善到 `-0.19 pp`；
- seed 1001 从 `+1.92 pp` 降至 `+1.17 pp`；
- 总体从接近零提高到 `+0.43 pp`。

选择性触发确实大幅减少了 seed 808 的正常记忆损伤，但没有使其转正。18 个单条件中没有任何一个在 Holm 校正后显著，因此总体收益仍属于弱效应，不能称为完成鲁棒防御。

## 5. 预注册主要约束未通过

阈值在 detector 测试集上维持了约 5% FPR，但在更新的正式干预样本上，平均 clean 触发率漂移到 6.32%。按污染时点分解：

| 时点 | 污染触发率 | clean 触发率 | 平均准确率变化 |
|---:|---:|---:|---:|
| swap after 4 | 61.59% | **9.06%** | +0.07 pp |
| swap after 8 | 54.12% | 3.58% | **+0.79 pp** |

主要问题不是随机测试集失效，而是 chunk 位置导致 clean 特征分布变化。统一阈值在较早时点过度触发，在较晚时点更加有效。由于预注册约束是 clean FPR ≤5%，正式部署阶段总体 6.32%，所以主要成功标准没有通过。

## 6. 更新后的结论

1. **污染是可观测的。** Memory 相对改写幅度能在不访问 donor、答案或 clean reference 的情况下检测污染，独立测试 AUC 达到 0.85–0.88。
2. **选择性干预优于固定干预。** 它将 seed 808 的损失从 -1.83 pp 缩小至 -0.19 pp，并获得总体 +0.43 pp。
3. **检测成功不自动等于防御成功。** 检出约 56% 污染后，净准确率收益仍小，说明触发后的统一 scale=0.20 不是样本级最优动作。
4. **校准同时依赖初始化和时间。** 跨模型排序可部分迁移，但阈值不迁移；同一模型在 chunk 4 和 chunk 8 也需要不同阈值。
5. **seed 808 反向已大幅缓解但未消除。** 当前 probe 避免了大部分过度干预，却仍有 280 个 harmed 对 266 个 corrected。

## 7. 建议下一阶段：Level 6.16.1

进入“时间校准与风险—收益决策”，不再只预测 clean/polluted 标签：

- 为不同 chunk 位置分别校准阈值，严格将每个时点 clean FPR 控制在 5%；
- probe 保留跨模型共同核心特征 rewrite_relative，但均值、方差和阈值按模型校准；
- 训练第二个 utility probe，直接预测某样本在 scale=0.20 下是 corrected、harmed 还是 unchanged；
- 只有污染风险高且预测收益为正时才触发；
- 在独立样本上预注册 seed 808 净收益 ≥0、总体 clean 触发率 ≤5%、总体净准确率 >0 三个联合条件；
- 同时比较 scale 0.20 与更温和的 0.25，减少高风险但依赖正常 Memory 的样本损伤。

Level 6.16 的真正突破是首次证明污染动力学可以从单条推理轨迹中检测；下一步需要把“检测污染”升级为“预测干预是否值得”。
