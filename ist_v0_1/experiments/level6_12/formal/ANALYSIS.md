# Level 6.12：第三层 32 槽位穷举因果图

## 协议核验

- 检查点：Level 6.8 `withdrawal_phase3.pt`
- 独立初始化：seed 606、808、1001
- 上下文：16 chunks × 128 tokens
- 每个模型、每个条件：400 个固定样本
- 条件：intact、32 个 keep-one、32 个 leave-one-out
- 总计：3 × 65 × 400 = 78,000 个样本级评估

三个模型 intact query accuracy 分别为 96.75%、96.25%、97.00%，平均 96.67%。

## 核心结论

第三层 Memory 呈现“多槽位充分、单槽位非必要”的高冗余因果结构。

1. **许多单槽位本身足以支持任务。**
   - seed 606：7/32 个槽位单独保留时达到至少 90%。
   - seed 808：2/32 个槽位达到至少 90%。
   - seed 1001：18/32 个槽位达到至少 90%。
   - 跨模型平均后，槽位 3、8、19、24、30、31 达到至少 90%。

2. **没有任何单槽位是不可替代的。**
   - 聚合 leave-one-out accuracy 全部位于 96.25%–97.33%。
   - 相对 96.67% intact，最大的聚合下降仅 0.42 个百分点。
   - seed 606 最大下降 0.50 pp；seed 808 最大下降 2.25 pp；seed 1001 删除任意单槽均未下降。
   - 因而不能把任务归因于某一个“核心槽位”；其余槽位可以补偿被删除槽位。

3. **槽位编号存在初始化依赖。**
   - 没有一个槽位在三个模型中都达到 90% keep-one accuracy。
   - 以较宽松的 80% 阈值，槽位 3、8、15、19、22、24、30、31 在三个模型中都具有较高单槽充分性。
   - 这表明模型会重复形成同类功能，但具体槽位分工会随随机初始化发生置换或重组。

4. **读取注意力不是可靠的因果解释。**
   - 聚合 attention–keep-one Pearson = -0.281，Spearman = -0.242。
   - 聚合 attention–necessity Pearson = 0.110。
   - 各种子相关性方向也不稳定。因此“读得多”不等于“该槽位单独足够”或“删除该槽位会造成损失”。

5. **槽位范数比注意力更接近充分性，但仍不是普适机制指标。**
   - norm–keep-one Pearson：0.567、0.976、0.675，三个种子均为正。
   - update-gate–keep-one Pearson：0.296、0.559、-0.858，跨种子不稳定。
   - 范数可作为候选槽位筛选信号，但最终仍须通过干预确认。

## 与 Level 6.10 / 6.11 的合并解释

- Tomography 显示几乎所有第三层槽位都能被 probe 解码。
- 本实验显示能被解码的槽位并不都以相同方式被模型使用。
- 多个槽位各自足以驱动行为，但删除任意一个又几乎无损。

所以第三层并非把记忆集中在单一槽位，而是形成了**分布式、重复编码、具有容错性的持久记忆表征**。这里必须区分三件事：信息可解码、单槽充分性、单槽必要性；三者并不等价。

## 下一步建议

进入 Level 6.13，做组合槽位因果图：

1. 从高充分性与低充分性槽位各取代表，穷举二元槽位组合；
2. 测量组合效应相对两个单槽效应的协同或拮抗；
3. 对每个模型搜索维持 90% accuracy 的最小槽位集合；
4. 对最小集合做补集删除，验证它们是否仍可被剩余槽位补偿；
5. 使用功能排序而不是固定槽位编号对齐不同随机种子。

这会回答当前实验尚不能回答的问题：冗余是简单复制，还是多个槽位之间存在非线性组合编码。
