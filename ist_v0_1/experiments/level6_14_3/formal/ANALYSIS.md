# Level 6.14.3：槽间传播因果图

## 协议核验

- 3/3 个模型完成
- 每模型 3 个预注册源槽位对
- 污染时间：chunk 4、8
- 每张图逐一恢复其余 30 个目标槽
- 每条件 3 个新评估种子，共 1,200 个配对样本
- 18 张完整传播图，540 条目标槽因果边
- 单图 30 个目标槽执行 Holm 校正
- 597 个实验条件全部完成

## 核心结论

第三层污染传播没有少数可识别的“中继槽”。30 个目标槽共同形成分布式传播场，单独
恢复任何一个目标槽都不足以稳定改变行为。结构路由强度、表示污染强度和更新门都不能
可靠预测单槽行为因果贡献。

## 1. 540 条单槽因果边无一通过校正

逐个恢复非源目标槽后：

- Holm 校正显著的准确率边：0/540
- Holm 校正显著的供体吸引边：0/540
- 最大单槽准确率恢复：+2.00 pp
- 最小单槽变化：-1.83 pp
- 平均单槽恢复：+0.198 pp
- 正向边 321 条，负向边 188 条，其余为零

即使最大单槽效应也远小于未修复污染造成的 20–41 pp 损失。没有一个目标槽可以被
称为必要传播中继。

## 2. 整层恢复有效，但任何单槽恢复无效

只恢复源槽位对后，相对 intact 仍残留：

- 1.67–6.25 pp 损失
- 平均残余损失 3.93 pp

恢复第三层全部 32 槽后：

- 18/18 张传播图精确回到 intact accuracy

因此残余信息确实存在于目标槽集合中，但它不是集中在某个目标槽，而是以集体形式
分布在多个槽位上。

## 3. 表示污染强度不预测行为因果贡献

每张图内部，目标槽 relative-L2 与单槽恢复增益的 Pearson 相关：

- 平均：0.036
- 范围：-0.529 到 +0.516

目标槽 donor projection 与行为增益：

- 平均：0.043
- 范围：-0.454 到 +0.506

方向随模型、源槽位对和污染时间翻转。一个槽位可以表现出强供体表示，却在单独恢复时
几乎不改变行为。这再次确认“表示含有信息”不等于“该表示单独具有行为必要性”。

## 4. 结构路由也不预测行为因果贡献

有效 source→destination 路由由：

```text
destination→token compression × token→source memory attention
```

组合得到。路由强度与单槽恢复增益的 Pearson 相关：

- 平均：0.094
- 范围：-0.610 到 +0.487

更新门与行为增益：

- 平均：-0.010
- 范围：-0.578 到 +0.518

因此 attention、compression 和 gate 描述的是模型的数据流结构，但不能直接当作行为
因果解释。它们在不同状态下可能有完全相反的行为意义。

## 5. 候选中继槽不具时间稳定性

比较同一模型、同一源槽位对在 swap-after-4 与 swap-after-8 的 Top-5 单槽恢复目标：

- 平均重合：1.33/5
- 最低：0/5
- 最高：2/5

若存在固定中继槽，两个时间点应出现高度重合；实际重合接近弱水平。传播目的槽随当前
Memory 状态动态变化，而非由固定槽位线路决定。

## 6. 为什么单槽恢复可能反向

188 条边出现轻微负效应。由于污染已经分布在多槽联合状态中，单独恢复一个槽可能：

1. 打破污染状态内部的一致性；
2. 使正确槽与剩余错误槽产生冲突；
3. 改变后续更新门和读取权重；
4. 在有限样本下产生小幅波动。

这些效应均未通过多重比较校正，不能解释为稳定的“有害正确槽”。它们支持的只是单槽
干预不足以解析集体动力学。

## 完整机制更新

```text
两个源槽注入供体身份
          ↓ 一个 chunk
供体成分同时扩散到约 30 个目标槽
          ↓
恢复任一目标槽：其余污染槽继续维持错误状态
          ↓
恢复全部第三层：行为精确恢复
```

污染传播图不是稀疏链：

```text
source A → relay X → relay Y → output
```

而更接近稠密广播与集体编码：

```text
source pair → distributed destination ensemble → output
```

## 与此前实验的统一解释

- Level 6.12：许多单槽充分，但单槽不必要；
- Level 6.13：许多双槽充分，但双槽通常不必要；
- Level 6.14.2：错误身份在一个 chunk 内扩散到第三层全部槽位；
- Level 6.14.3：任何单个目标槽都不是传播必要节点。

正确信息与错误信息都通过同一分布式冗余机制传播。该机制使删除错误具有容错性，却使
可信污染成为全层集体状态。

## 下一步建议：Level 6.14.4 群组恢复剂量曲线

单槽分辨率已经证明不适合解释集体传播。下一步应做目标槽群组干预：

1. 恢复 K = 1、2、4、8、16、30 个目标槽；
2. 分别按 donor projection、结构路由、单槽因果排序选择；
3. 与多组随机 K 槽恢复比较；
4. 绘制 accuracy recovery 与 donor-attraction reduction 的剂量曲线；
5. 测量群组效应是否超出单槽效应之和，定位非线性恢复阈值。

这会回答污染集体状态需要清除多少比例的槽位才能发生相变式恢复，以及表示/路由指标
是否只在群组尺度上具有预测力。
