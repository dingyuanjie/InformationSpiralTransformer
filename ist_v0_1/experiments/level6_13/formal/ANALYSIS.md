# Level 6.13：第三层槽位组合因果分析

## 协议核验

- 模型：seed 606、808、1001 三个独立初始化
- 上下文：16 chunks × 128 tokens
- 每个组合条件：400 个固定样本
- 每模型：496 个 keep-pair + 496 个 leave-pair-out
- 完成度：3/3 模型，2,976/2,976 个组合干预
- 样本级评估总量：1,190,400

## 主要结果

### 1. 跨初始化的最小共同充分集合大小为 2

Level 6.12 中没有任何固定单槽位能在三个初始化上都达到 90%。本轮发现
43 个固定槽位对在三个模型上都达到至少 90% keep-pair accuracy。因此：

- 对每个模型分别看，最小充分集合仍然是 1 个槽位；
- 要求固定槽位编号跨三个初始化通用时，最小充分集合从 1 收敛为 2。

按三个模型中最差准确率排序，最稳健的槽位对包括：

| 槽位对 | 三模型最差准确率 |
|---|---:|
| (13, 28) | 92.25% |
| (19, 26) | 92.25% |
| (2, 13) | 92.00% |
| (0, 10) | 91.75% |
| (5, 8) | 91.75% |
| (19, 30) | 91.75% |
| (27, 30) | 91.75% |

按三模型平均值，最佳组合为 (19, 30)，平均准确率 94.50%。

### 2. 组合图呈功能家族，而非孤立核心槽位

达到 90% 的 keep-pair 数量分别为：

- seed 606：254/496
- seed 808：99/496
- seed 1001：405/496

热图表现为明显的横纵条带：某些槽位能够与大量伙伴形成充分组合。这更符合
“功能家族 + 冗余伙伴”的结构，而不是少数固定槽位对独占记忆功能。

### 3. 存在互补增益，但没有纯 AND/XOR 型组合

相对两个成员中较好的单槽位，最大组合增益为：

- seed 606：+26.50 pp，槽位对 (10, 17)，63.00% / 54.75% → 89.50%
- seed 808：+10.50 pp，槽位对 (6, 23)
- seed 1001：+0.50 pp
- 三模型平均最大增益：+7.83 pp，槽位对 (10, 17)

没有发现“两个单槽均低于 20%，组合后超过 80%”的槽位对。因此当前证据支持
渐进式互补或冗余恢复，不支持信息必须由两个弱槽非线性合取才能读取的纯
AND/XOR 机制。

### 4. 双删仍未暴露跨初始化的关键故障对

每个模型中最大的 leave-pair-out accuracy drop 为：

- seed 606：5.00 pp
- seed 808：3.25 pp
- seed 1001：所有双删均未低于 intact 基线
- 跨模型平均最大下降：1.83 pp

最大聚合下降出现在 (1, 31) 和 (1, 30)，均为 1.83 pp。最大聚合联合删除交互为
(30, 31)，1.75 pp。没有固定槽位对在三个模型上都产生灾难性下降。

所以冗余至少超过两个槽位：即使同时删除两个槽位，剩余 30 个槽位通常仍能补偿。

### 5. 初始化改变的是槽位分工，不是总体计算策略

同一个固定槽位对在不同模型上的成员角色可以完全变化。例如 (13, 28)：

- seed 606：两个成员都较强，组合 92.75%；
- seed 808：13 强、28 弱，组合 92.25%；
- seed 1001：13 弱、28 强，组合 95.00%。

模型稳定学会了“多个可替代记忆载体”，但具体由哪个槽位承担主要功能会随初始化
置换。这解释了为何固定槽位编号的单槽结论不稳定，而双槽集合可以跨种子稳定。

## 证据边界

496 个槽位对会产生明显的多重比较问题。当前输出只保存每个条件的聚合准确率，
没有保存逐样本预测，因此无法对顶部 3–5 pp 热点进行配对 McNemar 检验。以下应视为
探索性候选，而不是已确认机制：

- seed 606 的 (10, 17) 大组合增益；
- seed 606 的 (1, 30)、(1, 12)、(10, 12) 双删交互；
- seed 808 的 (2, 7) 双删交互。

跨三个模型共同达到阈值的 43 个充分槽位对，以及双删整体影响很小的总体分布，
比单个极值更可靠。

## 合并结论

Level 6.10–6.13 共同支持：第三层 Memory 是分布式、重复编码、可重组且具有多槽级
容错性的持久记忆系统。信息可从多数槽位解码，多个单槽或双槽集合足以驱动行为，
但单删或双删通常都不必要。可解码性、充分性、必要性和组合协同是四个不同层面。

## 下一步：Level 6.13.1 定向组合复验

不再继续盲目扩大组合阶数。应保存逐样本预测，并对预注册的少量槽位对用更多样本、
多个评估种子复验：

1. 每模型选择最大正协同、最大双删交互、稳定通用对和负对照；
2. 每条件至少 2,000 个样本，使用相同样本做配对比较；
3. 计算 McNemar 检验、bootstrap 置信区间和 Holm 多重比较校正；
4. 判断 seed 606 的大效应是真正槽位互补，还是 496 对搜索产生的极值。
