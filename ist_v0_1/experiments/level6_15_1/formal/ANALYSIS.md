# Level 6.15.1：关键窗口与剂量精细复验

## 1. 完成情况

- 3 个独立模型种子：606、808、1001。
- 每个模型 3 个预注册槽位组合 × 2 个污染时点，共 18 个污染设定。
- 每条件使用 3 个全新的评估种子，每个种子 400 个样本，共 1200 个样本。
- 261 个条件全部完成；逐样本预测、每模型结果和图均已保存。
- 本阶段评估种子与 Level 6.15 不重合。

## 2. 预注册主假设：未通过

预注册条件为：污染后的第一个后继 chunk，同时将 SpiralAttention 历史读取和 MemoryAttention 历史传播缩放至 0.25，并要求三个模型种子的平均准确率都提高。

| 模型种子 | 平均准确率变化 |
|---:|---:|
| 606 | +1.17 pp |
| 808 | **-0.57 pp** |
| 1001 | +1.33 pp |
| 18 个设定总体 | +0.64 pp |

18 个设定中 10 个提高、8 个下降，仅 2 个单设定通过实验内 Holm 校正。总体均值为正，但 seed 808 方向为负，因而没有满足预注册的跨初始化确认标准。

Level 6.15 中该条件的总体增益为 +1.34 pp，且三个模型均为正；使用新评估样本后降至 +0.64 pp，并出现一个模型反向。因此应把“0.25 单步干预是稳定防御”降级为：**存在小幅平均信号，但效应对模型和样本敏感，尚未形成可靠防御。**

Matched-time 干净对照没有显示性能代价：该条件的干净准确率平均提高约 0.49 pp。不过这不改变污染鲁棒性未通过确认的判定。

## 3. 探索性剂量曲线

| 首个后继 chunk 的传播比例 | 平均准确率变化 | 正/零/负设定 | Holm 显著设定 | 干净准确率变化 |
|---:|---:|---:|---:|---:|
| 0.10 | +0.87 pp | 11 / 1 / 6 | 4 / 18 | +0.44 pp |
| **0.20** | **+1.13 pp** | **14 / 0 / 4** | **5 / 18** | +0.58 pp |
| 0.25 | +0.64 pp | 10 / 0 / 8 | 2 / 18 | +0.49 pp |
| 0.30 | +0.51 pp | 12 / 0 / 6 | 1 / 18 | +0.26 pp |
| 0.40 | +0.35 pp | 12 / 0 / 6 | 1 / 18 | +0.32 pp |

探索范围内 0.20 的总体结果最好，但其模型均值为 `+1.78 / -0.28 / +1.88 pp`，seed 808 仍未转正。因此 0.20 是下一轮候选剂量，不是已经确认的新最优值。

剂量曲线不是简单的“抑制越强越好”。0.20 最佳、0.10 次之，之后随传播比例升高总体效应递减，支持一个位于低传播区间的窄剂量窗口。

## 4. 时间窗口定位

固定 scale=0.25 时：

| 干预位置 | 平均准确率变化 | 正/零/负设定 |
|---|---:|---:|
| 污染后第 1 个 chunk | +0.64 pp | 10 / 0 / 8 |
| 污染后第 2 个 chunk | +0.47 pp | **14 / 0 / 4** |
| 污染后第 3 个 chunk | +0.19 pp | 8 / 1 / 9 |
| 污染后连续第 1、2 个 chunk | **+1.17 pp** | 11 / 0 / 7 |

传播敏感期不是严格单点，而更像污染后的前两个 chunk。第二个后继 chunk 的效应较小，但方向一致性最好，且三个模型均值都为正（`+0.24 / +0.76 / +0.40 pp`）。第三个后继 chunk 已接近无效。

连续两步干预取得最高平均增益 +1.17 pp，7 个设定通过 Holm 校正，但模型均值为 `+1.78 / -0.65 / +2.38 pp`，仍受到 seed 808 反向影响。因此它提示污染在前两步持续扩散，但尚不具备跨模型稳定性。

## 5. 传播支路拆分

| 单步 scale=0.25 支路 | 平均准确率变化 | 干净准确率变化 |
|---|---:|---:|
| 两条支路同时抑制 | +0.64 pp | +0.49 pp |
| 仅 SpiralAttention 历史读取 | +0.10 pp | -0.57 pp |
| 仅 MemoryAttention 历史传播 | +0.48 pp | -0.47 pp |

主要改善信号来自 **MemoryAttention → 新 Memory 写入** 支路，而不是历史 Memory 对当前 token 的 SpiralAttention 读取。两条支路同时干预略强于仅干预 MemoryAttention，可能存在弱协同，但差值很小，不能据此声称显著协同。

仅 SpiralAttention 干预在三个模型上的均值约为 `+0.14 / +0.15 / 0.00 pp`，基本没有实际效应。这进一步把污染扩散定位到 Memory 的递归重写，而不是当前 chunk 对旧 Memory 的一次性读取。

## 6. 与 Level 6.14–6.15 合并后的机制结论

1. donor swap 首先污染第三层源槽，随后通过第三层 MemoryAttention 重写扩散到分布式状态。
2. 污染传播的敏感期集中在后续前两个 chunk，第三个 chunk 后单步抑制几乎失效。
3. 正常信息和污染共享递归写入通路，因此长期关闭传播会严重损害任务；短时低剂量抑制只带来约 0.5–1.2 pp 的改善。
4. 防御效应明显依赖初始化。seed 808 对所有首步剂量以及连续两步干预均为负，表明固定的统一传播比例不是可靠的跨模型机制。
5. 当前证据支持“传播窗口存在”，但不支持“固定 0.25 单步门控已经构成稳定鲁棒方案”。

## 7. 建议下一阶段：Level 6.15.2

下一步不应继续无边界扫描固定比例，而应解释 seed 808 为什么反向：

- 对三个模型记录污染后前 3 个 chunk 的 MemoryAttention 输出范数、写入门、旧/新 Memory 夹角和 donor 投影；
- 对比同一样本在干预下由错误变正确、由正确变错误的两组轨迹；
- 仅在 MemoryAttention 支路测试 0.10、0.15、0.20、0.25，并把第 1、2 个 chunk 分开；
- 使用模型内归一化剂量，例如按干净轨迹传播范数的分位数缩放，而不是所有初始化共享同一绝对比例；
- 将 seed 808 作为预注册困难模型，任何新机制必须先在 seed 808 上不恶化，再检查其余模型。

目标应从“寻找统一固定 scale”转为“找出可观测的污染传播强度，并据此进行模型内校准干预”。
