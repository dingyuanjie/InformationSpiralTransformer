# Level 6.14.2：污染传播 Tomography

## 协议核验

- 3/3 个独立模型完成
- 每模型 3 个预注册槽位对
- 污染时间：chunk 1、4、8、12
- 恢复延迟：1、2 chunks
- 恢复范围：源槽位对、第三层全部槽位、三层全部 Memory
- 每条件：3 个新评估种子，共 1,200 个配对样本
- 255 个条件全部完成
- clean/polluted 双轨逐 chunk 保存 3 layers × 32 slots tomography

## 核心结论

污染传播路径已经被唯一定位：**错误身份只在第三层 Memory 内横向传播，从两个源槽位
扩散到其余 30 个槽位；它不会传播到前两层 Memory，也不存在独立于 Memory 的持久
隐藏状态。**

## 1. 注入瞬间污染严格局限于源槽位

在 swap 执行后的同一时刻：

- 两个源槽位相对 clean 轨迹发生大幅偏移；
- 第三层其余 30 个槽位偏移严格为 0；
- 第一层和第二层全部 64 个槽位偏移严格为 0。

源槽位相对 L2 偏移约为 0.62–1.46，具体尺度随模型、槽位对和时间变化。这说明实验
确实只在指定两个槽位注入污染，没有实现泄漏。

## 2. 一个 chunk 后污染扩散到第三层其余全部槽位

仅经过下一次 Memory 更新，第三层非源槽平均相对 L2 偏移变为：

- 最小：0.2971
- 最大：0.5491
- 平均：0.4220

非源槽沿供体样本方向的平均投影为：

- 最小：0.0882
- 最大：0.2511
- 平均：0.1413

因此非源槽变化不只是一般轨迹扰动，其中包含可测量的供体身份成分。热图呈现从两个
高强度源槽向整层扩散的横向传播图案。

## 3. 前两层在完整轨迹中保持精确零污染

所有模型、槽位对、交换时间和后续 chunk 中：

```text
max(|layer 0 relative displacement|) = 0
max(|layer 1 relative displacement|) = 0
```

这不是“接近零”，而是数值上精确为零。污染没有逆向进入前两层 Memory。传播完全
发生在第三层 Memory 的自身更新动力学中。

## 4. 只恢复源槽无法撤销已扩散污染

延迟 1–2 chunks 后只恢复原始两个槽位：

- 相对 intact 仍残留 0.92–7.83 pp 行为损失；
- 平均残余损失为 4.26 pp；
- 延迟越长，通常残余越大。

因此 Level 6.14.1 中观察到的残余损伤不是源槽位修复不精确，而是其他 30 个第三层
槽位已经继承污染。

例如 seed 606、(10,17)、swap-after-8：

- intact：97.00%
- 保持污染：66.75%
- delay-1 只恢复源槽：92.92%
- delay-2 只恢复源槽：90.58%
- 恢复第三层全部槽位：97.00%

## 5. 恢复第三层全部槽位足以精确恢复

在 3 模型 × 3 槽位对 × 4 污染时间 × 2 延迟 = 72 个条件中：

- 恢复第三层全部 32 槽：72/72 与 intact accuracy 逐值完全相等；
- 恢复三层全部 Memory：72/72 与 intact accuracy 逐值完全相等；
- 两种恢复范围之间：72/72 完全相等。

这构成双重定位：

1. 第三层全部恢复可以消除所有残余行为损伤，因此持久污染全部存放在第三层 Memory；
2. 额外恢复前两层没有收益，因此前两层没有隐藏污染；
3. 全部 Memory 恢复后轨迹精确回归 clean，说明不存在跨 chunk 持久化的非 Memory
   隐状态。

## 6. 传播速度和强度具有初始化差异

第三层非源槽在一个 chunk 后的典型偏移：

- seed 606：约 0.30–0.35
- seed 808：约 0.43–0.52
- seed 1001：约 0.37–0.55

seed 808 与 seed 1001 的横向传播通常更强，但最终行为脆弱性还取决于槽位读取方式，
不能仅由 L2 距离预测。这与此前“表示强度不等于行为因果利用”的结论一致。

## 完整因果路径

```text
第三层两个槽位被替换为供体状态
              ↓ 同一时刻
污染仅存在于两个源槽位
              ↓ 一个 chunk 的第三层 Memory 更新
供体方向成分扩散到第三层其余 30 槽
              ↓
只修复源槽：显式污染消失，扩散副本仍保留
              ↓
恢复第三层全部槽：行为与 clean 精确重合
```

结合 Level 6.14.1，可以确定：模型约 75% 的污染错误直接选择供体标签；这种身份代码
由第三层内部的槽间更新快速复制。缺失 Memory 能触发冗余补偿，而错误 Memory 会借用
同一冗余复制机制扩散。

## 当前机制结论

第三层 Memory 的容错机制和污染放大机制实际上是同一套动力学：

- 正确信息被多槽复制，因此单槽/双槽删除可恢复；
- 错误身份同样被多槽复制，因此交换污染会快速扩散；
- 冗余提高了删除鲁棒性，却降低了对可信但错误状态的鲁棒性。

这是一个明确的架构权衡：**redundancy is both error correction and error amplification**。

## 下一步建议：Level 6.14.3 槽间传播因果图

下一阶段应定位第三层 30 个目标槽中，哪些槽负责传播和最终行为损伤：

1. 在污染传播一个 chunk 后，逐个恢复 30 个非源槽；
2. 测量每个目标槽对准确率、供体吸引和后续扩散的因果贡献；
3. 结合 memory-update attention、update gate 与 donor projection；
4. 构建 source-pair → destination-slot 的有向传播图；
5. 检验高表示污染槽是否也是高因果传播槽。

这会把当前的整层定位推进到具体槽间传播通路。
